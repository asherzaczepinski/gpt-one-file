Doing it for real · about $1

Train on RunPod

One command rents a GPU, trains a bigger version of your model on far more story text, copies the results back to your Mac, and deletes the pod. It's capped so the whole thing costs about $1.

The command

In the Terminal app, from the gpt-one-file folder:

caffeinate -i bash runpod/train_on_runpod.sh

For a different budget, put it in front:

BUDGET=0.50 caffeinate -i bash runpod/train_on_runpod.sh

It prints progress every 2 minutes. Leave the charger in. It takes about as long as the budget buys (roughly 2–3 hours for $1 on a cheap GPU).

The code is runpod/train_tinystories.py: the same forward and backward as main_functionized_cuda.py, with a different data loader and a time-budgeted training loop. A tiny version was tested on your Mac and runs start to finish (trains, saves the best model, writes stories).

What the command does, step by step

  1. Checks the balance through RunPod's API, and stops if there isn't enough. 
    curl -H "Authorization: Bearer $APIKEY" https://api.runpod.io/graphql -d '{"query":"{ myself { clientBalance } }"}'
  2. Rents a GPU, trying cheap ones in order until one is in stock (RTX 2000 Ada, A4000, A4500, A5000, 4000 Ada: the same list your Race Hawks recordings use), with the same CUDA image. 
    mutation { podFindAndDeployOnDemand(input: { imageName: "runpod/pytorch:1.0.2-cu1281-torch280-ubuntu2404",
  gpuTypeId: "NVIDIA RTX 2000 Ada Generation", gpuCount: 1, cloudType: SECURE, containerDiskInGb: 30,
  ports: "22/tcp", env: [{ key: "PUBLIC_KEY", value: "<your ssh key>" }] }) { id costPerHr } }

    Everything goes through RunPod's GraphQL API at api.runpod.io/graphql. The older rest.runpod.io address stopped existing in November 2026, which is why the first try failed.

  3. Works out the time limit from the price. For example, at $0.30/hr, $1 × 0.95 buys 190 minutes. It takes 15 minutes off for setup, so it trains for 175 minutes.
  4. Waits for SSH, then sets a self-destruct timer on the pod: when the limit is up, the pod deletes itself through the API. That works even if your Mac falls asleep or loses wifi, so it can't run past the budget.
  5. Copies the training script up and starts setup + training in the background on the pod, so an SSH hiccup can't kill it: 
    pip install --break-system-packages cupy-cuda12x tiktoken numpy   # Ubuntu 24.04 blocks plain pip
curl -sL https://huggingface.co/datasets/roneneldan/TinyStories/resolve/main/TinyStoriesV2-GPT4-train.txt | head -c 400000000 > tinystories.txt
TEXT_FILE=tinystories.txt TRAIN_MINUTES=175 python -u train_tinystories.py
  6. Shows progress every 2 minutes: train loss, test loss on stories it never saw, and the best so far. The best model is saved whenever the test loss improves.
  7. Copies the results back to runpod/results/: out/best_model.pkl, out/stories.txt (4 stories it writes at the end) and train.log.
  8. Deletes the pod and checks it's really gone. Your encode test found a DELETE that didn't take once, so it repeats the delete until the pod is no longer listed. It also deletes the pod if the script crashes or you press Ctrl+C. Then it prints the balance before and after.

Four safety nets against spending too much: (1) it won't start without enough balance, (2) training is planned to fit the budget, (3) the pod's own timer deletes it at the limit no matter what, (4) the script deletes and double-checks the pod at the end, or on any crash or Ctrl+C.

How the first real run went (Nov 21, 2026)

Cost $0.93 on an RTX 2000 Ada at $0.24/hr. 17.4 million learned numbers, 97.5 million tokens of TinyStories, 26,900 tokens/sec, 87,619 steps in 222 minutes. Test loss went from 10.15 (random) to 1.545, and it never started memorizing. Pod deleted and verified at the end.

To write your own stories with it on the Mac (no GPU needed):

.venv/bin/python runpod/write_story.py "Once upon a time, a dog"

After it's done

cat runpod/results/out/stories.txt      # the stories it wrote
cat runpod/run_log.txt                  # everything that happened, with times and the balance before/after

To double-check nothing is still running (and costing money), open runpod.io → Pods. It should be empty.

Things to know

  • How smart will it get? Clearly better than today's: more coherent sentences that stay on topic longer, because it has 450× more text and remembers twice as far back. But it's still a small model, so don't expect perfect stories. The test loss numbers can't be compared directly with today's 3.48, because a different set of text gives a different vocabulary.
