What you're looking at

Every token is a dice roll. For each new token the model runs the whole forward pass you built (embeddings, 6 blocks of attention + MLP, the head) on the last 128 tokens, and gets a score for all 24,596 tokens it knows. Those scores become probabilities, and it rolls a weighted die.

Temperature divides the scores before the softmax. Below 1 it makes the favorite even more likely (careful, repetitive). Above 1 it flattens everything out (creative, then nonsense). Top-k throws away everything except the k best tokens before rolling, so it can never pick something really unlikely.

Shading: the darker a word's background, the less sure the model was when it picked it. Names, plot twists and the first word after a period are usually dark. Words that finish a phrase ("once upon a time") are usually clear.

Crossed-out prompt tokens never showed up in TinyStories, so the model has no row for them and skips them. Try "Minecraft" or "algorithm": it has never seen them. (It does know "spaceship", "volcano" and "pizza".)
